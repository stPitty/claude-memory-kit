- [human-prefs-communication](human-prefs-communication.md) — how the user wants me to communicate and report
- [human-prefs-coding](human-prefs-coding.md) — coding style, languages, tooling preferences and chronic corrections
- [human-prefs-workflow](human-prefs-workflow.md) — git, review, planning and delivery workflow preferences
- [projects/](projects/MEMORY.md) — per-project memory directories
